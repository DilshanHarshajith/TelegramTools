API Credentials Required

To use TelegramTools, you need to provide your Telegram API credentials. These will be saved to your .env file.

How to get credentials:
  1. Log in to my.telegram.org
  2. Go to "API development tools"
  3. Create a new application (if you haven't already)
  4. Copy the App api_id and App api_hash
